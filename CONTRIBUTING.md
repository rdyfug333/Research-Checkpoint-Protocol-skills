# Contributing / 贡献指南

Please open an issue or pull request with a focused description of the proposed change. Keep the Skill cross-project, preserve the distinction between documented state and experiment evidence, and describe any observed behavior or validation limits accurately. Run the Skill Creator validator when changing `SKILL.md` or its resources, if the validator is available in your Codex installation.

Do not submit credentials, private research data, model weights, or generated experiment outputs. Include third-party code or assets only when their licenses permit redistribution, and preserve their notices and attribution. Changes to the English and Chinese usage instructions should remain consistent.

欢迎通过 Issue 或 Pull Request 提交聚焦的改进。请保持 Skill 的跨项目适用性，并准确说明证据、测试范围及限制。修改 Skill 文件后，如本机提供 Skill Creator Validator，请运行验证。

请勿提交密钥、私人科研数据、模型权重或实验输出。引入第三方代码或资源前应确认其再分发许可，并保留原有版权声明与署名；中英文使用说明应保持一致。
